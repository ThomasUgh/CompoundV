> Most heroes don't get their powers in a lab.
> On your server, they will. **One bottle at a time.**

CompoundV is a modular ability plugin inspired by *The Boys*. Players drink experimental serums to roll for super powers — from flight and heat vision to a one-shot chest beam that vaporizes anyone in its path. Every ability has real controls, real cooldowns, and real consequences.

🧪 **Drink. Pray. Survive.** 🧪

## 🧪 The Serums

| Serum | Color | What it does |
| :-: | :-: | :-- |
| **Compound V** | 💙 | The classic. Random ability, permanent until death. Heroes are extremely rare. |
| **Temp V** | 💚 | A weaker, time-limited dose. Power fades after a configurable duration. |
| **V One** | 🩵 | The refined formula. Only rolls top-tier abilities. |
| **Anti V** | ❤️ | The cure. Drink to remove your current ability. |
| **V-Null Virus** | 🟣 | A bio-weapon. Infects and strips abilities from Compound V / Temp V / V One users on hit. |

> 🖱️ **Right-click** a bottle to drink. After a short activation, your power is unlocked.

All serums are crafted at the **workbench** using a chain of ingredients. Use `/cv tutorial` to receive the in-game handbook with every crafting step.

## 🎮 Ability Controls — Quick Reference

| Action | Input |
| :-- | :-: |
| Toggle ability (Heat Vision, Speedster, Ghost Mode, Beams…) | **F** *(swap offhand)* |
| Secondary ability / Special attack | **Sneak + Left-Click** |
| Special ability 2 / X-Ray / Chest Beam | **Sneak + Right-Click** |
| Jump Start *(Patriot, Sonic Boom, Stormstrike…)* | **Sneak + look up + Jump** |
| Double Jump *(Countess, Warrior…)* | **Jump** while in the air |
| Wall Climb *(SpiderWeaver)* | **Sneak** while touching a wall |
| Drink a serum | **Right-Click** with bottle in hand |

> 📖 Run `/cv tutorial` in-game to receive a full written handbook with every crafting chain and control reference.

## 📋 Commands & Permissions

<details>
<summary><b>📜 Commands</b></summary>
<br>

Main command: `/compoundv` — alias: `/cv`

| Command | Description | Permission |
| :-- | :-- | :-: |
| `/cv help` | Show in-game help | everyone |
| `/cv info [player]` | View your or another player's active ability, version and plugin stats | everyone / admin |
| `/cv tutorial` | Receive the in-game crafting & ability handbook | everyone |
| `/cv give <player> bottle <compoundv\|tempv\|vone\|antiv\|vnull>` | Give a serum bottle | admin |
| `/cv give <player> <ability> [potionType]` | Directly assign an ability | admin |

## ❓ FAQ

<details>
<summary><b>💀 What happens when I die with an ability?</b></summary>
<br>

By default, you lose it. Same risk Vought's heroes never had — and exactly what makes serums valuable and PvP genuinely tense.

</details>

<details>
<summary><b>⏱️ How long do Temp V abilities last?</b></summary>
<br>

The duration is rolled per drink between `min_duration_minutes` and `max_duration_minutes` (default: 15–120 min). When the timer runs out, the ability fades automatically.

</details>

<details>
<summary><b>🎲 Why is The Patriot so rare?</b></summary>
<br>

By design. Default weight is `1` against a combined pool of ~100+, so expect many bottles per Patriot roll. Tweak the weight in `config.yml` if you want him more common.

</details>

<details>
<summary><b>🧪 Can two players have the same ability?</b></summary>
<br>

Yes. Every drink rolls independently — there's no global lock.

</details>

<details>
<summary><b>🔧 Can I disable abilities or change roll chances?</b></summary>
<br>

Yes. Set any ability's chance to `0` in `config.yml` to disable it, or adjust the number to influence roll frequency. Run `/cv reload` to apply without restart.

</details>

<details>
<summary><b>🌍 What languages are supported?</b></summary>
<br>

English, German, Spanish, French, Hindi, Russian and Simplified Chinese ship out of the box. Set `language: en` (or `de`, `es`, `fr`, `hi`, `ru`, `zh`) in `config.yml`. Drop a custom file into `plugins/CompoundV/lang/` to add more.

</details>
